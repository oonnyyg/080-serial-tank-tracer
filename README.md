# 串联全混池示踪分析工具（tracer_train）

计算入口浓度变化在一系列串联全混流反应器（CSTR）中的传播，并用后向欧拉离散
推进，同时核对示踪剂质量收支。仅使用 Python 标准库（Python >= 3.12）。

## 用法

```bash
python -m tracer_train examples/input.json --out 输出目录
```

输入为 JSON 文件，可以是情景数组，也可以是 `{"scenarios": [...]}`。
每个情景的 `name` 必须非空且在该文件内唯一。

### 情景字段

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `name` | 情景名称 | 非空字符串，文件内唯一 |
| `volumes` | 按水流顺序排列的各池体积 V_i | 非空数组，每项有限且 > 0 |
| `initial_concentrations` | 各池初始浓度 | 与 `volumes` 等长，每项有限且 >= 0 |
| `flow_rate` | 恒定流量 Q（全部池相同） | 有限且 > 0 |
| `end_time` | 终止时刻（秒） | 有限且 > 0 |
| `inlet_schedule` | 入口浓度时间表 `[[t, C], ...]` | 从 0 开始，时刻严格递增且不超过终止时刻，浓度有限且 >= 0 |
| `step_size` | 步长网格间隔（秒），可选，默认 1.0 | 有限且 > 0 |

入口时间表采用“节点新值作为后续区间浓度”的分段常值约定：`t_k` 时刻给出的
浓度适用于区间 `[t_k, t_{k+1})`，最后一段持续到 `end_time`。

## 输出

输出目录下每个情景生成一个逐步 CSV（文件名由情景名清洗得到），外加一个
`summary.json`：

- `<情景名>.csv`：首行为表头 `time_s, tank_1_concentration, ...`，包含
  **初始状态（t = 0）**及每个步末的各池浓度，最后一行时刻一定是终止时刻。
- `summary.json`：每个情景的参数、记录步数与质量收支
  （`initial_mass`、`final_mass`、`cumulative_input`、`cumulative_output`、
  `residual`）。

任一情景非法时，CLI 返回退出码 2，在标准错误中给出含情景名和字段定位的原因，
并且**不创建/不写出任何成功文件**（所有情景先整批计算通过后才写盘）。

## 离散公式

池内瞬时均匀混合，无反应、无损耗，全部池流量相同。对第 i 个池（i = 1..N），
在长度 Δt 的步上采用**后向欧拉**，所有浓度取本步末值：

```
V_i (C_i^n - C_i^{n-1}) / Δt = Q (C_{i-1}^n - C_i^n)
```

令 α_i = Q·Δt / V_i，按水流顺序逐池求解（首池入口 C_0^n 取当前时间区间的
入口浓度值，后续各池入口取上游池**本步末**浓度）：

```
C_i^n = (C_i^{n-1} + α_i · C_{i-1}^n) / (1 + α_i)
```

这样各池在同一步内是耦合求解的，既不把各池独立计算，也不使用上游上一步的
旧浓度。

### 步边界

步边界取以下集合的并集：

- 0；
- 从 0 开始的正步长网格点（`step_size, 2·step_size, ...`，不超过终止时刻）；
- 入口浓度变化点；
- 终止时刻。

因此数值推进**不会跨越入口变化点**；当步长网格越过终止时刻时，最后一段
自动截断到终止时刻，终止时刻必被记录。

## 单位与质量收支

单位由输入自行约定，全程保持一致：

- 浓度 C：质量/体积；
- 体积 V：体积；
- 流量 Q：体积/秒，时间一律以秒计；
- 质量（池内存量 V·C、进出质量 Q·Δt·C）：随输入保持一致，不做任何归一化。

每个步按与离散格式一致的口径累计：

- 流入质量：`Q · Δt · C_in`（本时间区间入口浓度）；
- 流出质量：`Q · Δt · C_N^n`（**末池本步末**浓度）。

残差定义为

```
residual = initial_mass + cumulative_input - cumulative_output - final_mass
```

由于记账口径与后向欧拉逐池更新完全一致，该残差应接近机器精度（示例约
1e-12 量级），不以相对误差或归一化掩盖问题。

## 步长对结果的影响

后向欧拉是一阶隐式格式，无条件稳定，但存在数值耗散：步长越大，浓度峰被
抹平/滞后得越明显；步长减小则结果趋近串联 CSTR 的解析响应。**不要求不同
步长给出相同数值**。步边界的并集规则保证：改变 `step_size` 时所有入口变化点
仍被精确捕捉，变化点与终止时刻附近不会出现“跨过半个区间”的误差。

## 测试

```bash
python -m unittest discover -s tests -v
```

测试覆盖：非法输入的定位信息、时间网格并集、后向欧拉单步公式、上下游耦合
（本步末口径）、离散质量收支近零，以及 CLI 的整批失败语义与输出文件。
